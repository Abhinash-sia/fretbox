# Fretbox

Fretbox is a unified campus operations platform digitizing academic, hostel, facility, security, communication, payment, and administrative workflows.

## Backend (Phase B0)

The backend foundation is built with Node.js, TypeScript, Express, MongoDB (Mongoose), and Redis.

For detailed setup, environment configuration, and architectural details, see the [`backend/`](./backend) directory:

- [Backend Documentation](./backend/README.md)
- [Architecture Overview](./backend/ARCHITECTURE.md)

### Quick Start (Backend)

```bash
cd backend
npm install
npm run dev
```
